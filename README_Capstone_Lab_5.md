## Project overview

This capstone notebook integrates the main cybersecurity AI components described in the lab manual:

- Input cleaning and privacy masking for messages and identifiers.
- Rule-based detection of phishing, malware, and ransomware indicators.
- A supervised Decision Tree for Normal/Suspicious login classification.
- A small TensorFlow/Keras neural network using scaled login features.
- Comparison of rule, Decision Tree, and neural-network outputs.
- Explanations using matched keywords, numeric warning reasons, and feature importance.
- Low/Medium/High risk assignment, recommended actions, and human-review controls.
- Five demonstration scenarios, a risk chart, and saved combined results.

## Safety and limitations

Use only synthetic or sanitized data. Do not open suspicious links, execute malware, scan networks, test live accounts, or upload institutional confidential data to Colab. Mask identifiers in screenshots, charts, and reports. The datasets are small and synthetic, so model accuracy is only a classroom demonstration and does not establish real-world performance. Model outputs are decision support, not proof; serious actions require authorized human verification.
